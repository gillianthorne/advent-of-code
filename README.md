# Advent of Code
I'm working through all Advent of Code challenges starting from its inception in 2015, hoping to finish every year. I'm currently solving problems in Python for 2015 but may switch languages later.

## Structure
Every year will have its own folder, and every year will have 25 folders for each day. Days will have at minimum `part1.py`, possibly `input.txt` if it isn't a single-line input, and `part2.py` if the second part requires substantial changes.
